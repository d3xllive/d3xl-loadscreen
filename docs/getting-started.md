# 🚀 Getting Started

Welcome to **D3XL Loading Screen V4**, an ultra-modern, standalone loading screen for FiveM servers with YouTube music support, dynamic video backgrounds, and interactive UI components.

## 📦 Requirements

- Any FiveM Server (QBCore, ESX, Qbox, or Standalone)
- Zero script dependencies required!

## ⚡ Installation Steps

1. **Download the Resource**
   Download the latest release or clone the repository into your FiveM server's resources folder:
   ```bash
   resources/[scripts]/fivem-d3xl-loadscreen
   ```

2. **Configure your Server**
   Open your `server.cfg` file and add the following line:
   ```cfg
   ensure fivem-d3xl-loadscreen
   ```

3. **Customize your Loading Screen**
   Open `config.js` and modify your server name, slogans, staff members, rules, gallery photos, and YouTube playlist.

4. **Start your Server**
   Restart your server or run `ensure fivem-d3xl-loadscreen` in your server console.
