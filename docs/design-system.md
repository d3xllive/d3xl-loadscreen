# 🎨 Color & Design System

D3XL Loading Screen V4 features a dark glassmorphic design inspired by [tgiann.com](https://www.tgiann.com/tr).

## 🟢 Color Palette Tokens

| Variable | Hex / Value | Usage |
|---|---|---|
| `--accent` | `#36FF9F` | Neon Mint — main brand accent, active buttons, glow effects |
| `--bg-dark` | `#0a0e14` | Deep Space Black — background canvas |
| `--cyan` | `#00f0ff` | Cyan highlight |
| `--pink` | `#ff0055` | Founder badge & danger elements |
| `--text-main` | `#ffffff` | Primary text |
| `--text-muted` | `#8899aa` | Secondary description text |

## 📐 Layout Components

- **Top Center User Welcome Pill**: Floating badge with avatar initials and username.
- **Bottom Navigation Pill Bar**: Floating glass widget with interactive icons.
- **Music Widget**: Glassmorphic Spotify-style track info and timeline.
- **Modal Cards**: Glassmorphic windows with backdrop blur and smooth scale-in animation.
