# ✨ Key Features

D3XL Loading Screen V4 is packed with high-end, customizable features designed for FiveM servers:

### 🎥 3 Background Modes
- **MP4 Video Mode**: Play local or CDN hosted MP4 video loops.
- **YouTube Video Mode**: Embed any YouTube video background seamlessly.
- **Photo Slideshow Mode**: Automatically cycle through gallery photos with smooth cross-fade transitions every 6 seconds.

### 🎵 YouTube & MP3 Music Player
- Simply provide a YouTube video URL or ID (e.g. `OV88I5g_oJc`).
- Track title, artist, and cover art are **automatically fetched from YouTube**.
- Full player controls: Play/Pause, Previous, Next, Timeline progress, and Seek bar.

### ⌨️ Interactive Keyboard Keybinds Inspector
- Full interactive keyboard UI inspired by tgiann.com.
- Click any key to display assigned server controls (Phone, Inventory, Emote Menu, Vehicle locks, etc.).

### 📰 Image Update Cards (Patch Notes)
- Display server update announcements with thumbnail images, titles, descriptions, and release dates.

### 🖼️ Server Gallery Showcase
- Display server roleplay moments and custom vehicle galleries in a grid modal.

### ⚙️ In-Game Live Settings Panel
- Players can toggle click sound effects, adjust volume, change background mode, and tweak background blur in real-time.
- All settings are saved locally to `localStorage` and persist across server sessions.
